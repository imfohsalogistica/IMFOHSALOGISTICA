CORRECCIONES CRÍTICAS APLICADAS
1. ORDEN MANUAL DE RUTA
   - Ya no depende únicamente del arrastre.
   - Cada parada tiene selector directo de posición.
   - En Acciones de ruta existe "Reordenar ruta manualmente".
   - Permite cambios arbitrarios como 1-2-3-4 -> 2-1-4-3.

PENDIENTES / LIMITACIONES CONOCIDAS DEL PILOTO
A. Google Maps real debe probarse con la Demo Key del usuario y su conexión de Internet. La integración está preparada, pero no se puede certificar desde este entorno la cuota/capacidades concretas de esa clave.
B. Modo offline completo (cola IndexedDB + resincronización de fotos/eventos) NO está implementado todavía. El piloto requiere conexión activa para confirmar eventos. No se agregó de último momento para no arriesgar la estabilidad de la presentación.
C. El piloto usa una PC como servidor central + Cloudflare Tunnel. Si esa PC se apaga o se cierra el lanzador, el acceso externo deja de funcionar. Es adecuado para el piloto, no para producción empresarial.
D. La base central del piloto aún no es PostgreSQL empresarial. La migración a base transaccional/cloud se hará después de validar el flujo real.
E. Flotilla, Solicitud de Vehículo y Combustibles y Costos conservan su base actual; sus rediseños profundos quedan para la siguiente iteración, tal como se acordó. Sí reciben/consumen información de km y operación cuando corresponde.

ACCESO DEL PILOTO
- Ejecutar INICIAR_PILOTO_INTERNET.bat en la PC servidor.
- Se genera ENLACE_PILOTO_PUBLICO.txt y ENLACES_PILOTO_PARA_COMPARTIR.txt.
- El MISMO enlace HTTPS se comparte a todos los usuarios.
- Cada usuario inicia sesión y el sistema aplica su rol.
- Para un mensajero también existe: Mensajeros -> Acceso ruta (opcional).
