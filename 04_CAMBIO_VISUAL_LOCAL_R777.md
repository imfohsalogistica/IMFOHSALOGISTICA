# Cambio visual local R7.7.7

Se incorporó una capa visual directamente en `index.html` para acercar la aplicación local
a las referencias aprobadas. Se conserva la funcionalidad existente y se mejoran:
- navegación lateral;
- tarjetas KPI;
- tablas;
- planificador;
- tarjetas de mensajeros;
- vista móvil;
- visibilidad de la casilla física.

La casilla se presenta desde `physicalBin`. Si el documento aún no contiene una casilla,
se muestra `—` hasta que el lector la capture.
